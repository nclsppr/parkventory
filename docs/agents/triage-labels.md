# Labels de triage

Les skills utilisent cinq rôles canoniques. Ce tableau associe chaque rôle au label de ce dépôt.

| Label dans `mattpocock/skills` | Label dans GitHub | Sens |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Un mainteneur doit évaluer le ticket |
| `needs-info` | `needs-info` | Une réponse de la personne qui a signalé le sujet est attendue |
| `ready-for-agent` | `ready-for-agent` | Le ticket est spécifié et prêt pour un agent sans supervision |
| `ready-for-human` | `ready-for-human` | Le ticket exige une intervention humaine |
| `wontfix` | `wontfix` | Le ticket ne sera pas traité |

Quand un skill mentionne un rôle, utiliser le label GitHub correspondant dans ce tableau.

Modifier la colonne GitHub si le vocabulaire du dépôt change.
